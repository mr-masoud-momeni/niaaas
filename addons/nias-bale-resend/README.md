# Nias Login - Bale OTP Resend

افزونهٔ مستقل برای Nias Login که بعد از پایان تایمر OTP، گزینهٔ «ارسال مجدد کد با پیام‌رسان بله» را روی همان دکمهٔ ارسال مجدد نمایش می‌دهد.

## ویژگی‌ها

- بدون تغییر در فایل‌های Nias Login
- بدون صفحه یا تنظیمات جدید در پنل وردپرس
- استفاده از API Key و Bot ID موجود در تنظیمات Nias Login
- استفاده از `Nias_SMS_Gateway::send_bale()` خود Nias
- تولید OTP جدید و به‌روزرسانی رکورد OTP موجود
- شروع دوباره تایمر بعد از ارسال موفق
- nonce و rate limit برای جلوگیری از درخواست‌های پیاپی

## نصب

پوشهٔ `addons/nias-bale-resend` را به مسیر زیر کپی کنید:

`wp-content/plugins/nias-bale-resend`

سپس از بخش افزونه‌های وردپرس، **Nias Login - Bale OTP Resend** را فعال کنید.

خود Nias Login نیز باید فعال باشد و تنظیمات بله در آن کامل شده باشد.

## رفتار

وقتی تایمر OTP در Nias تمام شود، متن دکمهٔ resend به:

`ارسال مجدد کد با پیام‌رسان بله`

تغییر می‌کند. کلیک روی آن مستقیماً از endpoint افزونهٔ جدید استفاده می‌کند و handler ارسال مجدد اصلی Nias اجرا نمی‌شود.
